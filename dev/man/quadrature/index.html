Quadrature and interpolation

These are SCTL's one-dimensional building blocks: classical quadrature rules (ChebQuadRule, LegQuadRule), generalized quadrature rules built for a given set of integrands (InterpQuadRule), and polynomial interpolation and differentiation (LagrangeInterp).

Classical rules

legquad(n) is the $n$-point Gauss-Legendre rule. It integrates polynomials of degree $2n-1$ exactly. chebquad(n) is Fejér's first rule: its nodes are the Chebyshev points of the first kind, $x_i = \tfrac12\left(1 - \cos\tfrac{(2i-1)\pi}{2n}\right)$, and its weights integrate the degree-$n-1$ Chebyshev interpolant exactly. Both rules are on $[0, 1]$ and are open, i.e. no node sits at an endpoint. For an interval $[a, b]$, rescale: $\int_a^b f \approx (b-a) \sum_i w_i f(a + (b-a) x_i)$.

f(x) = exp(-x) * cos(4x)
exact = (1 - exp(-1) * (cos(4) - 4sin(4))) / 17          # ∫₀¹ f
for n in (4, 8, 12, 16)
    xl, wl = legquad(n)
    xc, wc = chebquad(n)
    @printf("n = %2d   Gauss-Legendre error %.1e   Fejér error %.1e\n",
            n, abs(dot(wl, f.(xl)) - exact), abs(dot(wc, f.(xc)) - exact))
end
n =  4   Gauss-Legendre error 1.9e-05   Fejér error 2.4e-03
n =  8   Gauss-Legendre error 6.3e-14   Fejér error 3.9e-07
n = 12   Gauss-Legendre error 1.2e-16   Fejér error 4.3e-12
n = 16   Gauss-Legendre error 4.6e-17   Fejér error 3.3e-16

Gauss-Legendre converges about twice as fast in $n$. Fejér nodes, on the other hand, are nested and convenient for Chebyshev interpolation.

legendre_poly(x, n) evaluates the Legendre polynomial $P_n$ and its derivative on $[-1, 1]$. The two rules are related: the Gauss-Legendre nodes are the roots of $P_n$, mapped to $[0, 1]$.

x, _ = legquad(7)
P, dP = legendre_poly(2 .* x .- 1, 7)
maximum(abs, P)                                           # P₇ vanishes at the nodes
1.9917192598100006e-15

Generalized (Chebyshev) quadrature

InterpQuadRule builds a rule with as few nodes as possible that integrates a given set of functions $\{\phi_j\}$ to a tolerance $\varepsilon$. This follows Bremer, Gimbutas and Rokhlin, SIAM J. Sci. Comput. 32 (2010):

  1. discretize the $\phi_j$ with a reference rule that resolves them;
  2. orthonormalize them (SVD or pivoted QR) and truncate at $\varepsilon$, leaving $k$ basis functions;
  3. pick $k$ stable interpolation nodes;
  4. compute the weights by least squares.

The result is a $k$-point rule that integrates every function in the span of the $\phi_j$ to about $\varepsilon$.

Typical uses are quadratures for singular or near-singular integrands, such as $x^m \log x$, which a polynomial rule resolves only slowly.

From a function

interp_quad_rule(f, a, b) adaptively discretizes the integrands on $[a, b]$ with composite Gauss-Legendre panels. f(x) receives a vector of nodes and returns a matrix with one column per integrand, M[i, j] = φⱼ(x[i]):

# integrands: x^k and x^k log(x), k = 0..9, on [0, 1]
phis(x) = hcat([x .^ k for k in 0:9]..., [x .^ k .* log.(x) for k in 0:9]...)
exact = vcat([1 / (k + 1) for k in 0:9], [-1 / (k + 1)^2 for k in 0:9])

xq, wq, cond = interp_quad_rule(phis, 0.0, 1.0; eps = 1e-12)
@printf("%d nodes, condition number %.1f, max error %.1e\n",
        length(xq), cond, maximum(abs, phis(xq)' * wq .- exact))
18 nodes, condition number 778.7, max error 3.7e-13

A Gauss-Legendre rule needs far more nodes to reach the same accuracy on these integrands:

for n in (20, 80, 320)
    xn, wn = legquad(n)
    @printf("Gauss-Legendre, %3d nodes: max error %.1e\n", n, maximum(abs, phis(xn)' * wn .- exact))
end
Gauss-Legendre,  20 nodes: max error 1.5e-03
Gauss-Legendre,  80 nodes: max error 9.7e-05
Gauss-Legendre, 320 nodes: max error 6.1e-06

From a discretization

When the integrands are already sampled, pass the samples M (nnodes × nfuncs) and the reference rule (nodes, weights) instead. interp_quad_rules builds a whole family of rules in one pass, one per tolerance in eps or per node count in order:

# reference rule: 30-point Gauss-Legendre panels on [2⁻ⁱ, 2¹⁻ⁱ], i = 1..50, refined towards the log singularity
xg, wg = legquad(30)
xs = vcat(xg ./ 2^50, [2.0^-i .* (1 .+ xg) for i in 1:50]...)
ws = vcat(wg ./ 2^50, [2.0^-i .* wg for i in 1:50]...)
M = phis(xs)

for (xr, wr, c) in interp_quad_rules(M, xs, ws; eps = [1e-4, 1e-8, 1e-12])
    @printf("%2d nodes: max error %.1e\n", length(xr), maximum(abs, phis(xr)' * wr .- exact))
end
 9 nodes: max error 1.7e-06
14 nodes: max error 9.7e-11
18 nodes: max error 2.2e-11

The keyword interval = (a, b) restricts the nodes to a subinterval. use_svd = false switches the orthogonalization to pivoted QR.

Lagrange interpolation and spectral differentiation

lagrange_interp_matrix(src, trg) returns the matrix $W$ of the barycentric Lagrange interpolant through the nodes src, evaluated at trg, so that W * f(src) ≈ f(trg). $W$ has size length(trg) × length(src). lagrange_interp applies it directly. lagrange_derivative(f, nodes) differentiates the interpolant at the nodes themselves.

On Chebyshev or Legendre nodes, both converge spectrally for smooth functions:

g(x) = 1 / (1 + 25 * (x - 0.5)^2)          # Runge's function, shifted to [0, 1]
dg(x) = -50 * (x - 0.5) / (1 + 25 * (x - 0.5)^2)^2
t = collect(range(0, 1; length = 1001))
for n in (8, 16, 32, 64)
    xc, _ = chebquad(n)
    e_int = maximum(abs, lagrange_interp(xc, g.(xc), t) .- g.(t))
    e_der = maximum(abs, lagrange_derivative(g.(xc), xc) .- dg.(xc))
    @printf("n = %2d   interpolation error %.1e   derivative error %.1e\n", n, e_int, e_der)
end
n =  8   interpolation error 8.8e-02   derivative error 1.2e+00
n = 16   interpolation error 3.9e-03   derivative error 1.8e-01
n = 32   interpolation error 7.6e-06   derivative error 1.4e-03
n = 64   interpolation error 2.9e-11   derivative error 2.1e-08

Several functions can be handled at once: pass a matrix with one column per function, and the result has the same shape.

x, _ = chebquad(12)
F = [sin.(x) cos.(x) exp.(x)]                # 12 × 3
D = lagrange_derivative(F, x)                # 12 × 3
maximum(abs, D .- [cos.(x) -sin.(x) exp.(x)])
7.926992395823618e-14

Pitfalls

  • Intervals differ. The quadrature rules are on $[0, 1]$, but legendre_poly is on $[-1, 1]$.
  • Rules are recomputed on every call. legquad(16) takes about 1 µs. In a hot loop, compute the rule once and reuse it.
  • Integrands must be resolvable. interp_quad_rule(f, a, b) refines until each panel reaches eps. Integrands that cannot be resolved there, such as non-integrable singularities or functions returning NaN/Inf, make the build fail or recurse deeply. Keep endpoint singularities integrable, as with $\log x$ or $x^{-1/2}$. The rule avoids the endpoints, because its nodes are interior.
  • Watch the condition number. It is the third return value. A rule with cond ≫ 10⁴ loses digits; loosen eps or reduce the number of integrands.
  • Nodes must be distinct. Lagrange interpolation divides by $x_i - x_j$. Equispaced nodes work but suffer the Runge phenomenon at high degree; use Chebyshev or Legendre nodes.

SCTL.interp_quad_rule — Function
interp_quad_rule(M, nodes, weights; eps=1e-16, order=0, interval=(0, 0), use_svd=true) -> (x, w, cond)

Generalized Chebyshev quadrature (InterpQuadRule): build a rule that integrates the functions sampled in the columns of M (M[i, j] = j-th integrand at nodes[i]), where nodes, weights is a quadrature that resolves them.

eps is the truncation tolerance and order (if > 0) caps the number of nodes. When interval = (a, b) with a != b, the nodes are picked from [a, b]. Returns the nodes, the weights and the condition number of the interpolation matrix. verbose=true lets SCTL print a summary of each rule. See DOI:10.1137/080737046.

source
interp_quad_rule(f, a, b; eps=1e-16, order=0, interval=(0, 0), use_svd=true) -> (x, w, cond)

Generalized Chebyshev quadrature for the integrands f on [a, b]: f(x::Vector{Float64}) returns a matrix with M[i, j] = j-th integrand at x[i]. The integrands are first discretized by an adaptive composite Gauss-Legendre rule to tolerance eps.

Build several generalized Chebyshev quadrature rules at once, one per entry of eps and/or order (if both are given they must have the same length and each rule uses the smaller node count). Returns a vector of (x, w, cond).
