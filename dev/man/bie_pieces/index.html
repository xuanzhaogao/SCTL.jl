Near-field pieces

A BoundaryIntegralOp adds two things for nodal densities F:

  • The far field: the smooth node quadrature over all nodes, evaluated by the FMM.
  • A sparse near correction C: for each element and each target close to it, the accurate quadrature minus the node rule.

\[U = K_{\mathrm{nodes}} F + C F, \qquad C_{e,t} = (\text{accurate rule of element } e \text{ at target } t) - (\text{node rule of } e \text{ at } t).\]

The functions on this page run the steps that build C one at a time and return plain Julia arrays. You can inspect or replace any step, for example by computing the accurate rule with a quadrature of your own, while keeping SCTL's classification and its far field:

The near test of near_list works for any discretization: you give it nodes, one radius per node and the number of nodes per element. So it also classifies panels that are not QuadElemLists.

The steps

The surface of the cube $[-1,1]^3$, with 2 × 2 flat elements of order 8 per face (normals outward):

el = QuadElemList(8, 24) do e, u, v
    f, r = divrem(e - 1, 4)                 # face f, element (i, j) on it
    i, j = divrem(r, 2)
    a, b = i + u - 1, j + v - 1             # face coordinates in [-1, 1]
    f == 0 ? [a, b, 1.0] : f == 1 ? [b, a, -1.0] : f == 2 ? [1.0, a, b] :
    f == 3 ? [-1.0, b, a] : f == 4 ? [b, 1.0, a] : [a, -1.0, b]
end
ff = far_field_nodes(el; tol = 1e-10)
extrema(ff.radius)
(0.7283051471658408, 1.0814921868369314)

A target is near an element if it lies within radius of one of the element's nodes. Here the targets are the surface nodes themselves:

nl = near_list(el; tol = 1e-10)
NearList(24 elements, 1536 targets, 11712 near pairs)
ts = near_targets(nl, 1)  # targets near element 1: its own 64 nodes, nodes of its neighbours on the same face and across the edges
(length(ts), nnodes(el))
(488, 1536)

The accurate rows come from SCTL's quadrature for the element list, here the double layer:

  • A target on a node of the element gets that node's row of the self-interaction matrix (Duffy rule, principal value).
  • Other targets get the near-singular rule: the element is split at the target's closest point and refined dyadically toward it.

Each block maps the element's nodal densities to its near targets, in the layout of kernel_matrix:

ker = Laplace3D_DxU()
q = ElemQuadrature(ker)
acc = near_blocks(q, el, nl, ff.X; tol = 1e-10)
size(acc[1])
(488, 64)

Subtracting the node rule of the same pairs and scattering the blocks gives the correction. Together with the node rule over all nodes (the far field), it is the boundary integral operator:

plain = node_rule_blocks(ker, el, nl, ff.X; tol = 1e-10)
C = assemble_near_correction(nl, acc, order(el)^2; subtract = plain)

F = randn(nnodes(el))
K = node_rule_block(ker, ff.X, ff.normal, ff.weights, ff.X)     # node rule, all nodes to all targets
op = BoundaryIntegralOp(ker; accuracy = 1e-10)
add_elem_list!(op, el)
norm(K * F + C * F - compute_potential(op, F)) / norm(compute_potential(op, F))
8.150773199848529e-14

For a constant density, the double layer is $-1/2$ on the surface (principal value):

extrema(K * ones(nnodes(el)) + C * ones(nnodes(el)))
(-0.5000000000003806, -0.4999999999899855)

near_correction runs all of these steps in one call.

Replacing a step: a quadrature written in Julia

Suppose you want your own rule for the targets that are near an element without lying on it. Here it is an upsampled tensor Gauss-Legendre rule:

  • evaluate the element's geometry at m × m points with elem_geom;
  • interpolate the nodal density to those points with lagrange_interp_matrix;
  • apply the kernel matrix.
function upsampled_block(ker, el, e, Xt; m = 32)
    u, w = legquad(m)
    g = elem_geom(el, e, u, u)                        # point (a, b) in column (a-1)*m + b
    W = vec(w * w') .* g.area                         # quadrature weights
    L = lagrange_interp_matrix(param_nodes(order(el)), u)
    P = kron(L, L)                                    # nodal values -> values at the m × m points
    return kernel_matrix(ker, g.X, g.normal, Xt) * (W .* P)
end

Its rows converge to SCTL's as m grows. The targets of element 1 on the neighbouring faces include nodes next to the shared edges, which are nearly singular for this rule:

off = findall(>(order(el)^2), ts)                     # targets near element 1 but not on it
for m in (16, 32, 64, 128)
    B = upsampled_block(ker, el, 1, ff.X[:, ts[off]]; m = m)
    @printf("m = %3d: max difference from SCTL's rows %.1e\n", m, maximum(abs, B - acc[1][off, :]))
end
m =  16: max difference from SCTL's rows 1.3e-01
m =  32: max difference from SCTL's rows 3.9e-02
m =  64: max difference from SCTL's rows 1.0e-03
m = 128: max difference from SCTL's rows 2.2e-05

To use it, replace those rows of the blocks and assemble as before. The classification, the self-interaction rows and the far field stay SCTL's:

mine = map(1:nelem(el)) do e
    B = copy(acc[e])
    ts = near_targets(nl, e)
    off = findall(t -> !(t in (e-1)*64+1:e*64), ts)
    B[off, :] = upsampled_block(ker, el, e, ff.X[:, ts[off]]; m = 128)
    B
end
C2 = assemble_near_correction(nl, mine, order(el)^2; subtract = plain)
norm((C2 - C) * F) / norm(K * F + C * F)
6.59710651935141e-5

Classifying other panels

near_list only needs node positions and radii, so it works for panels from another code. The radius can come from your own accuracy criterion, or from SCTL's rule as in far_field_nodes:

  • In parameter space, the rule takes the distance from each Gauss-Legendre node to the Bernstein ellipse with ρ = (64 / (15 tol))^(1/(2 order)).
  • It scales that by the tangent length.
r = fill(0.25, nnodes(el))                            # e.g. a fixed radius
targets = [0.5 0.0; 0.5 0.0; 1.1 3.0]                 # one target above element 4 (top face), one far away
nl_mine = near_list(ff.X, r, 64, targets)
[(e, collect(near_targets(nl_mine, e))) for e in 1:nelem(el) if !isempty(near_targets(nl_mine, e))]
1-element Vector{Tuple{Int64, Vector{Int64}}}:
 (4, [1])

Layouts and conventions

  • Matrices (near_matrix, the blocks, self_matrices, node_rule_block) are (dof × targets) × (src_dim × nodes of the element). Rows run target by target, dof components each; columns run node by node, src_dim components each. This is the layout of kernel_matrix. They include the quadrature weights, so they act on nodal density values.
  • dof is trg_dim(kernel). With target normals it is trg_dim/3: the potential dotted with the normal, as with trg_normal_dot_prod. Components 3(k-1)+1 : 3k are dotted for the k-th output.
  • Node order in assemble_near_correction: element e's nodes are consecutive, as in QuadElemList.
  • Targets on a node are matched by exact equality of coordinates. Pass the node coordinates themselves, e.g. far_field_nodes(el).X.
  • Cancellation. The node rule here is a full-precision kernel_matrix. The far field it cancels should be computed the same way to rounding: a direct sum (kernel_matrix, kernel_eval), or an FMM (ParticleFMM) at the accuracy you need.

Reference

SCTL.far_field_nodes — Function
far_field_nodes(elist; tol = 1e-10) -> (; X, normal, weights, radius)

The far-field (smooth node) quadrature of elist and the near radius of each node, as BoundaryIntegralOp uses them at accuracy tol: node positions X and unit normals normal (3 × nnodes), weights (area element times tensor Gauss-Legendre weights) and radius. Beyond radius[i] of every node i of an element the node rule is accurate to tol; closer targets are near the element (see near_list). The radius is the distance to the Bernstein ellipse of ρ = (64 / (15 tol))^(1/(2 order)) in parameter space, scaled by the tangent length.

SCTL.NearList — Type
NearList

Which targets are near which element: the targets near element e are near_targets(nl, e) (sorted, 1-based), stored compressed as nl.trg[nl.ptr[e]:nl.ptr[e+1]-1]. nl.ntrg is the number of targets. From near_list, or construct it yourself (NearList(ptr, trg, ntrg)) for your own criterion.

SCTL.near_list — Function
near_list(Xs, radius, nodes_per_elem, Xt) -> NearList
near_list(elist, Xt = nothing; tol = 1e-10) -> NearList

SCTL's near test (that of BoundaryIntegralOp, an octree search): target t is near element e if it lies within radius[i] of some node i of e.

The first form works for any discretization: source nodes Xs (3 × Ns, element by element), one radius per node, and nodes_per_elem (an integer, or one count per element); targets Xt (3 × Nt). The second takes the nodes and radii of far_field_nodes(elist; tol), with the surface nodes as default targets.

SCTL.ElemQuadrature — Type
ElemQuadrature(kernel)

The singular and near-singular quadratures of QuadElemLists for kernel (one of bie_supported_kernels()), without an operator: near_matrix, near_blocks and self_matrices return the accurate element-to-target matrices that BoundaryIntegralOp builds in its setup. The scheme is the element list's (set_quad_scheme!).

All matrices map nodal densities of one element to potentials at targets, laid out like kernel_matrix: (dof*Nt) × (src_dim*nnode), row (t-1)*dof + j, column (i-1)*src_dim + k for node i of the element, with dof = trg_dim(kernel) (or trg_dim/3 when target normals are given: the potential dotted with the normal, as in trg_normal_dot_prod). They include the quadrature weights.

SCTL.near_matrix — Function
near_matrix(q::ElemQuadrature, elist, e, Xt; normals = nothing, tol = 1e-10) -> Matrix

The accurate matrix from element e of elist to the targets Xt (3 × Nt), by elist's near-singular rule (split at each target's closest point, refined toward it). For targets that coincide with a node of the element use near_blocks or self_matrices. Layout: see ElemQuadrature.

SCTL.self_matrices — Function
self_matrices(q::ElemQuadrature, elist; tol = 1e-10, trg_normal_dot_prod = false) -> Array{Float64,3}

The singular (self-interaction) matrices of all elements: S[:, :, e] maps the nodal densities of element e to the potential at its own nodes (the principal value for the Duffy and tensor-product schemes), (dof*nnode) × (src_dim*nnode). With trg_normal_dot_prod the potential is dotted with the element normal at each node.

SCTL.near_blocks — Function
near_blocks(q::ElemQuadrature, elist, nl::NearList, Xt; normals = nothing, tol = 1e-10) -> Vector{Matrix{Float64}}

The accurate matrices of all near pairs, as BoundaryIntegralOp builds them (in parallel): block e maps element e's nodal densities to its near targets near_targets(nl, e) (in that order). A target that coincides with a node of the element gets the self-interaction row of that node (with the element's normal for the dot product). Layout: see ElemQuadrature.

SCTL.node_rule_block — Function
node_rule_block(kernel, Xs, Xn, w, Xt; normals = nothing) -> Matrix

The plain node rule from source nodes Xs (normals Xn for kernels with source normals, else nothing; weights w) to the targets Xt: kernel_matrix with each source column scaled by its weight, dotted with the target normals if given. This is what the far field (FMM) contributes for a pair, and what a near correction subtracts. Layout as ElemQuadrature.

node_rule_block for every element of elist and its near targets, with the far-field nodes of far_field_nodes: the part of the far field that a near correction replaces.

SCTL.assemble_near_correction — Function
assemble_near_correction(nl::NearList, blocks, nodes_per_elem; src_dim = 1, dof = 1, nsrc = nothing,
                         subtract = nothing) -> SparseMatrixCSC

Scatter per-element blocks (block e: (dof * length(near_targets(nl, e))) × (src_dim * nodes of e), layout as ElemQuadrature) into the sparse (dof*Nt) × (src_dim*Nsrc) matrix acting on all nodal densities, element e's nodes being consecutive. With subtract (blocks of the same shapes, e.g. node_rule_blocks) the entries are blocks[e] - subtract[e]: the near correction, to be added to the node rule. The blocks can come from any quadrature, e.g. one written in Julia.

source
SCTL.near_correction — Function
near_correction(kernel, elist; targets = nothing, normals = nothing, trg_normal_dot_prod = false, tol = 1e-10)
    -> (C, nl)

SCTL's near correction for elist, assembled from the pieces (near_list, near_blocks, node_rule_blocks, assemble_near_correction): the sparse matrix C such that

U = (node rule over all nodes) * F + C * F

is BoundaryIntegralOp's potential at the targets, for nodal densities F. Targets default to the surface nodes; trg_normal_dot_prod = true there dots the potential with the surface normals, or give normals for other targets. Returns the near list too, so the pieces can be recomputed or replaced selectively.
