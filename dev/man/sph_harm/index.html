Spherical harmonics

This module wraps sctl::SphericalHarmonics<double> (header sctl/sph_harm.hpp). It covers spectral calculus on the unit sphere $S^2$:

  • scalar transforms between values on a tensor-product grid and spherical harmonic coefficients (grid2shc, shc2grid), including $θ$/$φ$ derivatives, plus evaluation at arbitrary points (shceval) and at the poles (shc2pole);
  • vector transforms for Cartesian vector fields on the sphere, expanded in vector spherical harmonics (grid2vecshc, vecshc2grid, vecshceval);
  • layer potentials of densities on the unit sphere, evaluated analytically in the spectral basis: Laplace single and double layer (laplace_eval_sl, laplace_eval_dl) and Stokes single layer, double layer and traction (stokes_eval_sl, stokes_eval_dl, stokes_eval_kl, stokes_eval_kself).

A real field of degree at most $p$ is represented as

\[f(θ,φ) = \sum_{n=0}^{p} \sum_{m=0}^{n} c_m \sqrt{4π}\, \bar P_n^m(\cos θ)\, \mathrm{Re}\big(A_{nm}\, e^{imφ}\big), \qquad c_0 = 1,\ c_{m>0} = 2,\]

where $\bar P_n^m(x) = \sqrt{\tfrac{2n+1}{4π}\tfrac{(n-m)!}{(n+m)!}}\, P_n^m(x)$ carries the Condon–Shortley phase, so $Y_n^m = \bar P_n^m(\cos θ) e^{imφ}$ is orthonormal. Equivalently $f = \sqrt{4π}\sum_{n}\sum_{m=-n}^{n} A_{nm} Y_n^m$ with $A_{n,-m} = (-1)^m \overline{A_{nm}}$. Only $m ≥ 0$ is stored. With this scaling $f ≡ 1$ has $A_{00} = 1$, the same normalization as the Fortran code SCTL's implementation follows.

The grid is the usual Gauss–Legendre × trapezoidal product grid: Nt latitudes with $\cos θ_i$ the Gauss–Legendre nodes on $[-1,1]$, and Np equispaced longitudes $φ_j = 2π j/N_p$. The transform is exact (up to rounding) for fields of degree $≤ p$ when Nt ≥ p + 1 and Np ≥ 2p + 1. A common choice is Nt = p + 1, Np = 2p + 2.

Use this module for problems posed on a sphere: spectral differentiation and filtering, interpolation of gridded data, and analytic (spectrally accurate, singularity-free) layer potentials on spherical boundaries, such as vesicle and particle models.

Tutorial

using SCTL, LinearAlgebra

Grid ↔ coefficient round trip

sph_grid_angles returns the grid angles. Grid values are stored with φ fastest, so the natural Julia array is (Np, Nt):

p = 8
Nt, Np = p + 1, 2p + 2
θ, φ = sph_grid_angles(Nt, Np)
grid(f) = [f(θ[i], φ[j]) for j in 1:Np, i in 1:Nt]          # size (Np, Nt)

# a band-limited field of degree 3
f(t, ph) = 0.7 + cos(t) - 0.4sin(t)cos(ph) + sin(t)^2 * cos(2ph) + 0.2sin(t)^3 * sin(3ph)
X = grid(f)
S = grid2shc(X, Nt, Np, p)                                  # length shc_length(p) = (p+1)(p+2)
X2 = shc2grid(S, p, Nt, Np)                                 # flat, reshape(X2, Np, Nt)
(length(S), shc_length(p), maximum(abs, X2 .- vec(X)))
(90, 90, 2.886579864025407e-15)

The coefficients can be evaluated on any other grid, which is spectral interpolation. With derivatives = true, shc2grid also returns $∂f/∂θ$ and $∂f/∂φ$:

ft(t, ph) = -sin(t) - 0.4cos(t)cos(ph) + 2sin(t)cos(t)cos(2ph) + 0.6sin(t)^2 * cos(t) * sin(3ph)
fp(t, ph) = 0.4sin(t)sin(ph) - 2sin(t)^2 * sin(2ph) + 0.6sin(t)^3 * cos(3ph)

Nt2, Np2 = 20, 31                     # finer output grid
θ2, φ2 = sph_grid_angles(Nt2, Np2)
grid2(g) = vec([g(θ2[i], φ2[j]) for j in 1:Np2, i in 1:Nt2])
F, Fθ, Fφ = shc2grid(S, p, Nt2, Np2; derivatives = true)
(maximum(abs, F - grid2(f)), maximum(abs, Fθ - grid2(ft)), maximum(abs, Fφ - grid2(fp)))
(7.327471962526033e-15, 2.042810365310288e-14, 1.972727536880825e-14)

Spectral convergence

A smooth but not band-limited function such as $e^{x} = e^{\sin θ \cos φ}$ converges exponentially in p. Here the error is measured with shceval at 200 scattered points on a Fibonacci spiral. The points form a 2 × N matrix of $(θ, φ)$ pairs:

g(t, ph) = exp(sin(t) * cos(ph))
N = 200
pts = [acos.(1 .- 2 .* ((1:N) .- 0.5) ./ N)'; mod.(2.399963 .* (1:N), 2π)']  # 2 × N: rows θ, φ
exact = [g(pts[1, k], pts[2, k]) for k in 1:size(pts, 2)]
function conv_err(p)
    Nt, Np = p + 1, 2p + 2
    θ, φ = sph_grid_angles(Nt, Np)
    S = grid2shc([g(θ[i], φ[j]) for j in 1:Np, i in 1:Nt], Nt, Np, p)
    return maximum(abs, shceval(S, p, pts) .- exact)
end
for p in (2, 4, 8, 12, 16)
    println("p = ", lpad(p, 2), "   max error = ", conv_err(p))
end
p =  2   max error = 0.07005025870023118
p =  4   max error = 0.0010148325904246747
p =  8   max error = 2.385897490686517e-8
p = 12   max error = 8.193445921733655e-14
p = 16   max error = 8.43769498715119e-15

shc2pole returns the values at $θ = 0$ and $θ = π$ directly. The Gauss–Legendre grid does not contain the poles:

S = grid2shc(X, Nt, Np, p)
shc2pole(S, p), (f(0.0, 0.0), f(π, 0.0))
([1.7000000000000046, -0.3000000000000006], (1.7, -0.30000000000000004))

Coefficient layouts for a tiny order

Take $p = 1$ and $f = 1 + 2\cos θ + \sin θ\cos φ - 3\sin θ\sin φ$. Its coefficients are $A_{00} = 1$, $A_{10} = 2/\sqrt3$, $A_{11} = (-1 - 3i)/\sqrt6$. The three SHCArrange layouts store them as follows:

p1 = 1
θ1, φ1 = sph_grid_angles(p1 + 1, 2p1 + 2)
h(t, ph) = 1 + 2cos(t) + sin(t)cos(ph) - 3sin(t)sin(ph)
H = [h(θ1[i], φ1[j]) for j in eachindex(φ1), i in eachindex(θ1)]
for arr in (SHC_ALL, SHC_ROW_MAJOR, SHC_COL_MAJOR_NONZERO)
    c = grid2shc(H, p1 + 1, 2p1 + 2, p1; arrange = arr)
    println(rpad(string(arr), 22), round.(c; digits = 6))
end
println("reference: A00 = 1, A10 = 2/√3 = ", round(2 / sqrt(3); digits = 6),
        ", A11 = (-1 - 3i)/√6 = ", round(-1 / sqrt(6); digits = 6), " ", round(-3 / sqrt(6); digits = 6), "i")
SHC_ALL               [1.0, 0.0, 0.0, 0.0, 1.154701, 0.0, -0.408248, -1.224745]
SHC_ROW_MAJOR         [1.0, 0.0, 1.154701, 0.0, -0.408248, -1.224745]
SHC_COL_MAJOR_NONZERO [1.0, 1.154701, -0.408248, -1.224745]
reference: A00 = 1, A10 = 2/√3 = 1.154701, A11 = (-1 - 3i)/√6 = -0.408248 -1.224745i

All three layouts store the same coefficients in different orders. Every routine takes the layout as the keyword arrange (default SHC_ROW_MAJOR), and a coefficient vector must be read back with the layout that produced it.

Several fields at once

Fields are stacked one after another (field-major) on input and in the coefficients. Point evaluations come back point-major:

X3 = cat(X, grid((t, ph) -> cos(t)^2); dims = 3)            # (Np, Nt, 2)
S3 = grid2shc(X3, Nt, Np, p)                                # [coeffs of field 1; coeffs of field 2]
V = reshape(shceval(S3, p, pts[:, 1:4]), 2, 4)              # V[k, i] = field k at point i
maximum(abs, V[2, :] .- cos.(pts[1, 1:4]) .^ 2)
2.3314683517128287e-15

Vector fields: the V/W/X decomposition

grid2vecshc takes the Cartesian components $(f_x, f_y, f_z)$ of a vector field on the grid, as an (Np, Nt, 3) array. It returns three coefficient blocks (V, W, X) for the expansion

\[\mathbf f = \sum_{n,m} V_{nm}\big(∇_s Y_n^m - (n+1) Y_n^m \hat{\mathbf r}\big) + W_{nm}\big(∇_s Y_n^m + n Y_n^m \hat{\mathbf r}\big) + X_{nm}\, \hat{\mathbf r} × ∇_s Y_n^m ,\]

so the radial part has coefficients $nW - (n+1)V$, the surface-gradient part has $V + W$, and the surface-curl part has $X$. Below, $\mathbf f = ∇_s \cos θ + 2\,\hat{\mathbf r}×∇_s \cos θ + 3\cos θ\,\hat{\mathbf r}$. Here $\cos θ$ has scalar coefficient $A_{10} = 1/\sqrt3$, so we expect gradient $1/\sqrt3$, curl $2/\sqrt3$ and radial $3/\sqrt3$:

er(t, ph) = [sin(t)cos(ph), sin(t)sin(ph), cos(t)]
eθ(t, ph) = [cos(t)cos(ph), cos(t)sin(ph), -sin(t)]
eφ(t, ph) = [-sin(ph), cos(ph), 0.0]
vf(t, ph) = -sin(t) .* eθ(t, ph) .- 2sin(t) .* eφ(t, ph) .+ 3cos(t) .* er(t, ph)

G = zeros(Np, Nt, 3)                                        # (Np, Nt, 3): x, y, z component grids
for i in 1:Nt, j in 1:Np
    G[j, i, :] = vf(θ[i], φ[j])
end
SV = grid2vecshc(G, Nt, Np, p)                              # length 3 * shc_length(p)
nc = shc_length(p)
k = 2 * (1 * 2 ÷ 2 + 0) + 1                                 # ROW_MAJOR index of Re A(1,0)
Vc, Wc, Xc = SV[k], SV[nc + k], SV[2nc + k]
n = 1
(gradient = (Vc + Wc) * sqrt(3), curl = Xc * sqrt(3), radial = (n * Wc - (n + 1) * Vc) * sqrt(3))
(gradient = 1.0, curl = 1.9999999999999998, radial = 3.0)

The inverse transform and pointwise evaluation reproduce the field:

err_grid = maximum(abs, vecshc2grid(SV, p, Nt, Np) .- vec(G))
U = reshape(vecshceval(SV, p, pts[:, 1:5]), 3, 5)           # 3 × N (one vector field)
err_pts = maximum(abs, U .- reduce(hcat, [vf(pts[1, i], pts[2, i]) for i in 1:5]))
(err_grid, err_pts)
(4.884981308350689e-15, 7.993605777301127e-15)

Laplace layer potentials on the unit sphere

Density $Y_n^m$ gives single-layer potential $r^n Y_n^m/(2n+1)$ inside the sphere and $r^{-n-1}Y_n^m/(2n+1)$ outside. Its double-layer potential is $-\frac{n+1}{2n+1} r^n Y_n^m$ inside and $\frac{n}{2n+1} r^{-n-1} Y_n^m$ outside. The interior keyword is required and selects the branch for all targets:

p = 4
σ1 = zeros(shc_length(p)); σ1[1] = 1                        # σ ≡ 1 (A00 = 1)
xin  = [0.1 -0.3  0.5; 0.2 0.4 0.0; -0.3 0.1 0.6]           # 3 × N inside
xout = [2.0  0.0 -1.0; 0.0 3.0 1.5; 0.5 -1.0 2.0]           # 3 × N outside
rout = vec(sqrt.(sum(abs2, xout; dims = 1)))
(
    sl_in  = maximum(abs, laplace_eval_sl(σ1, p, xin; interior = true) .- 1),        # = 1
    sl_out = maximum(abs, laplace_eval_sl(σ1, p, xout; interior = false) .- 1 ./ rout), # = 1/r
    dl_in  = maximum(abs, laplace_eval_dl(σ1, p, xin; interior = true) .+ 1),        # = -1 (Gauss)
    dl_out = maximum(abs, laplace_eval_dl(σ1, p, xout; interior = false)),           # = 0
)
(sl_in = 1.1102230246251565e-16, sl_out = 5.551115123125783e-17, dl_in = 1.1102230246251565e-16, dl_out = 0.0)

For a general density, the single layer is continuous across the sphere, and the double layer jumps by the density, $u^+ - u^- = σ$:

σ(t, ph) = 1 + cos(t)^3 - sin(t)^2 * sin(2ph)
θp, φp = sph_grid_angles(p + 1, 2p + 2)
Sσ = grid2shc([σ(θp[i], φp[j]) for j in eachindex(φp), i in eachindex(θp)], p + 1, 2p + 2, p)
ys = [0.6 -0.48 0.0; 0.0 0.6 0.8; 0.8 0.64 -0.6]            # points on |y| = 1
σy = [σ(acos(ys[3, i]), atan(ys[2, i], ys[1, i])) for i in 1:3]
(
    sl_jump = maximum(abs, laplace_eval_sl(Sσ, p, ys; interior = false) .- laplace_eval_sl(Sσ, p, ys; interior = true)),
    dl_jump = maximum(abs, laplace_eval_dl(Sσ, p, ys; interior = false) .- laplace_eval_dl(Sσ, p, ys; interior = true) .- σy),
)
(sl_jump = 4.440892098500626e-16, dl_jump = 8.881784197001252e-16)

Stokes layer potentials on the unit sphere

The Stokes routines take the vector spherical harmonic coefficients of the density, as produced by grid2vecshc, and return velocities or tractions as 3 × N. A uniform density $\mathbf f = \mathbf e_z$ is a translating rigid sphere. Its single layer equals $\tfrac23 \mathbf e_z$ inside. Outside it is a Stokeslet of total force $\mathbf F = 4π\mathbf e_z$ plus a source dipole:

\[\mathbf u(\mathbf x) = \frac{1}{8π}\Big[\frac{I}{r} + \frac{\mathbf x\mathbf x^T}{r^3} + \frac13\Big(\frac{I}{r^3} - \frac{3\mathbf x\mathbf x^T}{r^5}\Big)\Big]\mathbf F .\]

The Stokes double layer of a constant density is $-\mathbf f$ inside and $0$ outside:

Gz = zeros(Np, Nt, 3); Gz[:, :, 3] .= 1                     # f = e_z on the p = 8 grid
p = 8
Sz = grid2vecshc(Gz, Nt, Np, p)
uin = reshape(stokes_eval_sl(Sz, p, xin; interior = true), 3, :)
Fz = [0, 0, 4π]
uex(x) = (r = norm(x); ((I / r + x * x' / r^3) + (I / r^3 - 3x * x' / r^5) / 3) * Fz / 8π)
uout = reshape(stokes_eval_sl(Sz, p, xout; interior = false), 3, :)
(
    sl_in  = maximum(abs, uin .- [0, 0, 2 / 3]),
    sl_out = maximum(abs, uout .- reduce(hcat, uex.(eachcol(xout)))),
    dl_in  = maximum(abs, reshape(stokes_eval_dl(Sz, p, xin; interior = true), 3, :) .- [0, 0, -1]),
    dl_out = maximum(abs, stokes_eval_dl(Sz, p, xout; interior = false)),
)
(sl_in = 2.220446049250313e-16, sl_out = 1.6653345369377348e-16, dl_in = 3.3306690738754696e-16, dl_out = 5.442605794341458e-18)

stokes_eval_kl returns the traction $(-PI + ∇\mathbf u + ∇\mathbf u^T)\boldsymbol ν$ at off-surface targets with given normals. stokes_eval_kself returns its one-sided limits on the sphere with $\boldsymbol ν = \hat{\mathbf r}$. The traction jumps by the density, exterior minus interior equals $-\mathbf f$. For the rigid translation, the interior flow is a uniform translation with zero stress, so the interior traction is $0$ and the exterior one is the uniform $-\mathbf e_z$. The total hydrodynamic force on the sphere is $-4π\mathbf e_z$, balancing the applied $\mathbf F$:

kin  = reshape(stokes_eval_kself(Sz, p, ys; interior = true), 3, :)
kout = reshape(stokes_eval_kself(Sz, p, ys; interior = false), 3, :)
klim = reshape(stokes_eval_kl(Sz, p, ys .* (1 + 1e-9), ys; interior = false), 3, :)  # just outside, ν = r̂
(interior = maximum(abs, kin), exterior = maximum(abs, kout .- [0, 0, -1]),
 jump = maximum(abs, kout .- kin .- [0, 0, -1]), kl_vs_kself = maximum(abs, klim .- kout))
(interior = 4.651176655909146e-16, exterior = 7.771561172376096e-16, jump = 1.2212453270876722e-15, kl_vs_kself = 2.8800001938833472e-9)

Pitfalls and limitations

  • Grid resolution. Use Nt ≥ p + 1 and Np ≥ 2p + 1. Coarser grids alias, and Fourier modes above Np ÷ 2 are silently dropped. A grid finer than needed just projects onto degree ≤ p, which acts as a low-pass filter.
  • Node order. sph_legendre_nodes(p1) returns p1 + 1 nodes (note the +1) in decreasing order, so $θ$ increases with the latitude index. The rule is on $[-1, 1]$ with weights summing to 2. This differs from legquad, whose nodes lie on $[0, 1]$.
  • interior selects one expansion for all targets. The layer-potential routines do not test $|x| < 1$. The interior branch $\propto r^n$ and the exterior branch $\propto r^{-n-1}$ are both evaluated without complaint at any radius, and the wrong branch gives wrong values. Split targets by radius yourself. On the sphere, the two branches give the one-sided limits.
  • The origin. Evaluating any layer potential at exactly $x = 0$ returns NaN, because SCTL forms $r^n$ as $r^{n+1}/r$. Use a tiny offset, or the known value: for the single layer at the center, only the $n = 0$ term survives.
  • Stokes densities are vector-SH coefficients. Pass the output of grid2vecshc, not scalar coefficients of the Cartesian components. Unit viscosity is assumed.
  • Order limits. SCTL's tables have SCTL_SHMAXDEG = 1024 entries, so scalar routines need p ≤ 1023, vector routines and the Laplace evaluators p ≤ 1022, and Stokes p ≤ 1021. Grids need Nt ≤ 1024 and Np ≤ 1023. The wrapper checks these limits, because SCTL's own asserts are compiled out.
  • Memory. The first call to any routine in this module allocates about 200 MB of mostly empty lookup tables, sized for all orders up to 1024. Precomputed Legendre and Fourier matrices and FFT plans are cached on top of that, per (p, Nt) or Np. sph_clear_cache (SphericalHarmonics::Clear()) frees everything, but the tables come back on the next call.
  • Threading. Every routine runs OpenMP-parallel internally (see SCTL.set_num_threads). The lazily built caches are filled inside named omp critical sections, so calling these routines concurrently from several Julia threads is safe. sph_clear_cache is not safe: it destroys tables that other threads may be reading. Call it only when no other spherical-harmonic call is in flight.
  • WriteVTK from SCTL is not wrapped.

API reference

SCTL.SHCArrange — Type
SHCArrange

Memory layout of the spherical harmonic coefficients of one scalar field of order p (degrees n = 0..p, orders m = 0..n; only m ≥ 0 is stored since the fields are real). A(n,m) = Ar(n,m) + i Ai(n,m) and the field is

\[f(θ,φ) = \sum_{n=0}^{p} \sum_{m=0}^{n} c_m \sqrt{4π}\, \bar P_n^m(\cos θ)\, \mathrm{Re}\big(A(n,m)\, e^{imφ}\big), \qquad c_0 = 1,\ c_{m>0} = 2,\]

where $\bar P_n^m(x) = \sqrt{\tfrac{2n+1}{4π}\tfrac{(n-m)!}{(n+m)!}}\, P_n^m(x)$ (Condon-Shortley phase included, so $\bar P_n^m(\cos θ) e^{imφ} = Y_n^m$ is orthonormal on the sphere). Equivalently $f = \sqrt{4π} \sum_{n} \sum_{m=-n}^{n} A(n,m) Y_n^m$ with $A(n,-m) = (-1)^m \overline{A(n,m)}$; in particular f ≡ 1 has A(0,0) = 1, and $\cos θ$ has $A(1,0) = 1/\sqrt{3}$.

Values (0-based offsets into the coefficient block of one field; see shc_length):

  • SHC_ALL: (p+1)×(p+1) complex numbers, row-major in (n, m), as interleaved (re, im) pairs: Ar(n,m) at 2*(n*(p+1) + m), Ai(n,m) at 2*(n*(p+1) + m) + 1; entries with m > n are zero. Length 2(p+1)^2.
  • SHC_ROW_MAJOR (default): the lower triangle (p+1)(p+2)/2 complex numbers, row-major, interleaved: Ar(n,m) at 2*(n*(n+1)/2 + m), Ai(n,m) right after it (Ai(n,0) = 0 is stored). Length (p+1)(p+2).
  • SHC_COL_MAJOR_NONZERO: (p+1)^2 real numbers, column-major (by m) without the zero imaginary parts: Ar(0:p,0), Ar(1:p,1), Ai(1:p,1), Ar(2:p,2), Ai(2:p,2), …, Ar(p,p), Ai(p,p). Length (p+1)^2.

Several fields are stored one after the other (field-major), so a coefficient vector has length nfields * shc_length(p, arrange) (3 * nfields * shc_length(p, arrange) for vector fields).

source
SCTL.shc_length — Function
shc_length(p, arrange=SHC_ROW_MAJOR) -> Int

Number of real coefficients of one scalar field of order p in the layout arrange (see SHCArrange): 2(p+1)^2 (ALL), (p+1)(p+2) (ROWMAJOR) or (p+1)^2 (COLMAJOR_NONZERO). A vector field has three times as many.

source
SCTL.sph_grid_angles — Function
sph_grid_angles(Nt, Np) -> (θ, φ)

Angles of the Nt × Np spherical grid used by grid2shc and friends: θ = acos.(sph_legendre_nodes(Nt-1)) (increasing, Gauss-Legendre in $\cos θ$) and φ = 2π .* (0:Np-1) ./ Np (equispaced).

Grid values of a field f are stored with φ fastest: X[j + Np*(i-1)] = f(θ[i], φ[j]), i.e. the Julia array X = [f(θ[i], φ[j]) for j in 1:Np, i in 1:Nt] of size (Np, Nt).

SCTL.sph_clear_cache — Function
sph_clear_cache()

Free SCTL's precomputed spherical harmonic matrices, FFT plans and quadrature rules (SphericalHarmonics::Clear). They are rebuilt on demand. Note that the first use of any spherical harmonic routine allocates about 200 MB of (mostly empty) lookup tables, sized for orders up to SCTL_SHMAXDEG = 1024; this call releases them too, but they are allocated again on the next use.

Not thread-safe: do not call while another thread uses the spherical harmonic routines.

SCTL.grid2shc — Function
grid2shc(X, Nt, Np, p; arrange=SHC_ROW_MAJOR) -> S::Vector{Float64}

Spherical harmonic coefficients of order p (layout arrange, see SHCArrange) of fields given by their values on the Nt × Np grid of sph_grid_angles (Gauss-Legendre in $\cos θ$ × equispaced in φ).

X holds nfields = length(X) ÷ (Nt*Np) fields, one after the other; each field is stored with φ fastest, so X may be an (Np, Nt) or (Np, Nt, nfields) array (or any array with that memory order; it is flattened). The result has length nfields * shc_length(p, arrange), field-major. The transform is exact (up to rounding) for band-limited fields of degree ≤ p when Nt ≥ p + 1 and Np ≥ 2p + 1; the Fourier modes m > Np ÷ 2 are dropped.

SCTL.grid2vecshc — Function
grid2vecshc(X, Nt, Np, p; arrange=SHC_ROW_MAJOR) -> S::Vector{Float64}

Vector spherical harmonic coefficients of vector fields (not necessarily tangent) given by their Cartesian components on the Nt × Np grid of sph_grid_angles.

X holds nvec = length(X) ÷ (3*Nt*Np) vector fields; each one is stored as its x, y, z component grids one after the other (each in the scalar grid layout, φ fastest), i.e. X may be an (Np, Nt, 3) or (Np, Nt, 3, nvec) array. The result has length 3 * nvec * shc_length(p, arrange): per vector field the three coefficient blocks (V, W, X) of the expansion

\[\mathbf f = \sum_{n,m} V_{nm} \mathbf V_n^m + W_{nm} \mathbf W_n^m + X_{nm} \mathbf X_n^m,\quad \mathbf V_n^m = ∇_s Y_n^m - (n+1) Y_n^m \hat{\mathbf r},\ \mathbf W_n^m = ∇_s Y_n^m + n Y_n^m \hat{\mathbf r},\ \mathbf X_n^m = \hat{\mathbf r} × ∇_s Y_n^m,\]

(with the scalar normalization of SHCArrange and $∇_s$ the surface gradient on the unit sphere), each block in the layout arrange.

SCTL.laplace_eval_sl — Function
laplace_eval_sl(S, p, coord; interior, arrange=SHC_ROW_MAJOR) -> Vector{Float64}

Laplace single-layer potential $u(x) = \int_{S^2} σ(y) / (4π|x - y|)\, dS_y$ of densities σ on the unit sphere given by their spherical harmonic coefficients S (order p), at the points coord (3×N matrix or flat [x1, y1, z1, …]). Density $Y_n^m$ gives $r^n Y_n^m/(2n+1)$ inside and $r^{-n-1} Y_n^m/(2n+1)$ outside, so σ ≡ 1 gives u = 1 for |x| < 1 and u = 1/|x| for |x| > 1.

interior (required) selects the interior (regular at the origin, for |x| ≤ 1) or the exterior (decaying, for |x| ≥ 1) expansion for all points. Result is point-major: reshape(U, nfields, N). The point x = 0 (exactly the origin) gives NaN in all the layer-potential evaluators (SCTL computes $r^{n}$ as $r^{n+1}/r$).

SCTL.laplace_eval_dl — Function
laplace_eval_dl(S, p, coord; interior, arrange=SHC_ROW_MAJOR) -> Vector{Float64}

Laplace double-layer potential $u(x) = \int_{S^2} σ(y)\, \partial_{n_y} \frac{1}{4π|x - y|}\, dS_y$ (outward normal $n_y = y$) of densities on the unit sphere. Density $Y_n^m$ gives $-\frac{n+1}{2n+1} r^n Y_n^m$ inside and $\frac{n}{2n+1} r^{-n-1} Y_n^m$ outside (so σ ≡ 1 gives -1 inside and 0 outside). Arguments and layout as in laplace_eval_sl.
